What’s in the PDF

Honest limits

The GSC UI export is capped at 1,000 rows. We report on the file we were given. Empty blocks are omitted. Rows are never invented.

Who it’s for

Freelance SEO practitioners and small-agency account managers who need a tidy two-pager after a reporting period — not another dashboard.

How to export

  1. Search Console → Performance → Search results
  2. Set the date range, then Export → Download CSV
  3. If you get a ZIP, open it and drop Queries.csv and/or Pages.csv

Official columns: Top queries or Top pages, Clicks, Impressions, CTR, Position. Query / Page aliases are accepted. CTR may be 12.3% or 0.123.
